Mathematical Operations

Broadcasting

numlin supports NumPy-style broadcasting. Arithmetic operations between differently shaped arrays are possible if their dimensions are compatible.

  • Matrix-Vector: Matrix (M, N) op Vector (N) applies the vector to every row.
  • Column-wise: Matrix (M, N) op Matrix (M, 1) applies the column to every row.

Logic & Comparisons

Comparison methods return a new array with uint8 DType containing 1 (true) or 0 (false).

  • .greater(scalar)
  • .less(scalar)
  • .equal(scalar)

Clipping

Restrict values to a specific range [min, max].

  • .clip(min, max): Returns a new array.
  • .clip_(min, max): In-place operation.

Universal Functions (uFuncs)

  • nl.sqrt(arr), nl.exp(arr), nl.log(arr)
