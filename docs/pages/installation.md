# Installation

Install the package via npm:

```bash
npm install numlin
```

## Module Support

`numlin` is a dual-module package, supporting both **ES Modules** and **CommonJS**.

### ES Modules (Modern Node.js & Browsers)
```typescript
import nl from 'numlin';
```

### CommonJS (Legacy Node.js)
```javascript
const { nl } = require('numlin');
```
