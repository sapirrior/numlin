# Introduction

`numlin` is a numerical computing library for TypeScript and Node.js. It provides a set of tools for vector and matrix operations, statistics, and mathematical utilities optimized for JIT execution environments.

By utilizing JavaScript `TypedArrays`, `numlin` ensures low-latency operations and predictable memory overhead.

## Core Concepts

The library centers around the `nl` object. Most operations are available as methods on `Vector` or `Matrix` instances or as static utilities on the `nl` object.
