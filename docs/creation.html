Array Creation

Methods for initializing vectors and matrices.

Basic Creation

nl.vector(data, dtype?)

Creates a 1-dimensional Vector.

const v = nl.vector([1, 2, 3]);

nl.matrix(data, shape?, dtype?)

Creates a 2-dimensional Matrix. If data is a flat array, the shape parameter is required.

const m = nl.matrix([[1, 2], [3, 4]]);

Utility Functions

  • nl.zeros(shape, dtype?): Initializes an array with zeros.
  • nl.ones(shape, dtype?): Initializes an array with ones.
  • nl.eye(n, m?, dtype?): Creates an identity matrix.
  • nl.arange(start, stop?, step?): Creates a range of values.
  • nl.linspace(start, stop, num): Creates evenly spaced values over a specified interval.
