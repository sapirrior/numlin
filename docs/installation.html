Installation

Install the package via the npm registry:

npm install numlin

Module Support

numlin is a dual-module package. It provides native support for both ES Modules (ESM) and CommonJS (CJS) environments.

ES Modules (Recommended)

For modern Node.js environments and browser-based build tools:

import nl from 'numlin';

CommonJS

For legacy Node.js environments or projects using require:

const { nl } = require('numlin');
