Matrix Class

The Matrix class represents 2-dimensional numerical data.

Operations

  • .dot(other): Matrix multiplication.
  • .transpose(): Matrix transpose.
  • .add(other), .subtract(other), .multiply(other) (Supports Broadcasting)

Data Integrity & Extraction

.copy()

Creates a deep copy of the matrix and its underlying buffer.

.slice(rowStart, rowEnd?)

Returns a new Matrix containing the specified rows. Supports negative indexing and out-of-bounds clamping.

Manipulation

.flatten()

Returns a Vector representation of the matrix. This is a zero-copy operation.

.toArray2D()

Converts the internal flat TypedArray into a standard JavaScript 2D array.
