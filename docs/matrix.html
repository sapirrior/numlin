Matrix Class

The Matrix class represents 2-dimensional numerical data.

Operations

.dot(other)

Performs matrix multiplication (dot product).

.transpose()

Returns a new Matrix representing the transpose of the original.

Manipulation

.flatten()

Returns a Vector representation of the matrix. This is a zero-copy operation.

.toArray2D()

Converts the internal flat TypedArray into a standard JavaScript 2D array.
