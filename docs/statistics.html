Statistics

The nl.statistics namespace provides numerically stable functions for data analysis.

Basic Reductions

  • sum(arr): Total sum of elements. Uses 4-way independent accumulators.
  • mean(arr): Arithmetic mean.

Numerical Stability

variance(arr) and std(arr)

Calculates variance and standard deviation using Welford's Online Algorithm. This approach is numerically stable and prevents precision loss (catastrophic cancellation) encountered in the naive "sum of squares" method.

Extrema

  • min(arr): Returns the minimum value. Returns NaN for empty arrays.
  • max(arr): Returns the maximum value. Returns NaN for empty arrays.
  • argmin(arr): Returns the index of the minimum value. Returns -1 for empty arrays.
  • argmax(arr): Returns the index of the maximum value. Returns -1 for empty arrays.
