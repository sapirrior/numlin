Vector Class

The Vector class represents 1-dimensional numerical data.

Operations

  • .add(other), .subtract(other), .multiply(other)
  • .add_(other), .subtract_(other), .multiply_(other) (In-place)
  • .dot(other): Vector dot product.

Data Integrity & Extraction

.copy()

Creates a deep copy of the vector and its underlying buffer.

.slice(start, end?)

Returns a new Vector containing a subset of the data. Follows standard JS slice semantics.

Manipulation

.reshape(rows, cols)

Converts the vector into a Matrix. Zero-copy operation.
