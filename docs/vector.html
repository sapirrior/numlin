Vector Class

The Vector class represents 1-dimensional numerical data.

Arithmetic

  • .add(other): Element-wise addition.
  • .subtract(other): Element-wise subtraction.
  • .multiply(other): Element-wise multiplication.

Linear Algebra

.dot(other)

Calculates the dot product of two vectors. Returns a scalar value.

Manipulation

.reshape(rows, cols)

Returns a Matrix view of the vector data. This is a zero-copy operation; the underlying data buffer is shared.
