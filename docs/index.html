numlin

A numerical computing library for TypeScript and Node.js.

Getting Started

numlin is designed for high-performance numerical operations. It utilizes JavaScript TypedArrays and JIT-optimized kernels to provide a robust engine for linear algebra and data science.

Installation

npm install numlin

Core Concepts

The library centers around the nl object. Most operations are available as methods on Vector or Matrix instances or as static utilities on the nl object.

Creation API

nl.vector(data, dtype?)

Creates a 1D Vector.

const v = nl.vector([1, 2, 3]);

nl.matrix(data, shape?, dtype?)

Creates a 2D Matrix. If data is flat, shape is required.

const m = nl.matrix([[1, 2], [3, 4]]);
const m2 = nl.matrix([1, 2, 3, 4], [2, 2]);

Utilities

  • nl.zeros(shape, dtype?): Array filled with zeros.
  • nl.ones(shape, dtype?): Array filled with ones.
  • nl.eye(n, m?, dtype?): Identity matrix.
  • nl.arange(start, stop?, step?): Range of values.
  • nl.linspace(start, stop, num): Evenly spaced values.

Vector Class

Inherits from NDArray. Represents 1D data.

.add(other) / .subtract(other) / .multiply(other)

Performs element-wise operations with another Vector or a scalar.

.dot(other) Returns Number

Calculates the dot product of two vectors.

.reshape(rows, cols) Zero Copy

Returns a Matrix view of the vector data without copying.

Matrix Class

Inherits from NDArray. Represents 2D data.

.dot(other)

Performs matrix multiplication (dot product).

.transpose()

Returns the transposed matrix.

.flatten() Zero Copy

Returns a Vector view of the matrix data.

.toArray2D()

Converts the internal flat data back into a 2D JavaScript array.

Mathematics

Optimized unary operations that work on both Vectors and Matrices.

  • nl.sqrt(arr)
  • nl.exp(arr)
  • nl.log(arr)

Statistics

Available under the nl.statistics namespace.

  • sum(arr): Calculates the total sum using ILP.
  • mean(arr): Calculates the arithmetic mean.

Random

Available under the nl.random namespace.

  • vector(length, dtype?): Uniform random vector [0, 1).
  • matrix(rows, cols, dtype?): Uniform random matrix [0, 1).
